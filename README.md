🧮 Calculadora em Ruby

📌 Sobre o projeto

Este projeto consiste em uma calculadora simples desenvolvida em Ruby.

O usuário recebe um menu de opções e pode escolher qual operação matemática deseja realizar utilizando dois números.

🎯 Objetivo

Praticar conceitos fundamentais da linguagem Ruby, como:

- Entrada de dados
- Variáveis
- Operações matemáticas
- Estruturas condicionais
- Estrutura de repetição
- "case"
- Interpolação de strings
- Validação de dados

📋 Menu de opções

O programa apresenta as seguintes opções:

1 - Soma
2 - Subtração
3 - Multiplicação
4 - Divisão
0 - Sair

Após escolher uma operação, o usuário informa dois números e o programa apresenta o resultado.

O menu continuará sendo exibido até que o usuário escolha a opção 0 - Sair.

💻 Exemplo de execução

=== CALCULADORA ===

1 - Soma
2 - Subtração
3 - Multiplicação
4 - Divisão
0 - Sair

Escolha uma opção: 1

Digite o primeiro número: 10
Digite o segundo número: 5

Resultado: 15

Divisão por zero

O programa também deve impedir uma divisão por zero e informar ao usuário que essa operação não é permitida.

🛠️ Tecnologias utilizadas

- Ruby

▶️ Como executar

Com o Ruby instalado, execute no terminal:

ruby calculadora.rb

📖 Projeto de estudo

Projeto desenvolvido para praticar operações matemáticas, estruturas de controle e interação com o usuário na linguagem Ruby.
